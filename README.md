# SmartResume Builder 🚀

A web-based resume builder built using Java, JSP, Servlets, JDBC, MySQL, Maven, and Apache Tomcat.

## Features
- User registration and login
- Resume creation and management
- Multiple resume templates
- Resume dashboard
- ATS checker
- Admin panel

## Tech Stack
- **Backend:** Java, JSP, Servlets, JDBC
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MySQL
- **Build Tool:** Maven
- **Server:** Apache Tomcat

## Run Locally
1. Clone this repository.
2. Configure your MySQL database.
3. Set the `SMARTRESUME_DB_URL`, `SMARTRESUME_DB_USER`, and `SMARTRESUME_DB_PASSWORD` environment variables.
4. Build using `mvn clean package`.
5. Deploy the generated WAR file to Apache Tomcat.
